# 📊 Super Store Sales Performance & Forecasting Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard developed to analyze Super Store sales and profit performance. It provides business insights through interactive visualizations, YoY analysis, regional analysis, and sales forecasting.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify monthly sales and profit trends
- Compare sales performance across regions
- Analyze category and sub-category performance
- Understand customer segment and payment mode distribution
- Analyze different shipping modes
- Forecast sales for the next 15 days

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Microsoft Excel / CSV Dataset

## 📂 Dataset

The project uses Super Store sales data containing information such as:

- Order Date
- Sales
- Profit
- Category
- Sub-Category
- Region
- Customer Segment
- Payment Mode
- Ship Mode

## 🔄 Project Workflow

### Step 1: Data Collection
Collected the Super Store sales dataset containing order, customer, product, sales, and shipping information.

### Step 2: Data Import
Imported the dataset into Power BI using the **Get Data** option.

### Step 3: Data Cleaning
Used Power Query to:
- Remove duplicate records
- Handle missing values
- Correct data types
- Rename columns where required
- Format date and numerical fields

### Step 4: Data Transformation
Created required columns and transformed the data to make it suitable for analysis.

### Step 5: Data Modeling
Created relationships between relevant tables and prepared the data model for reporting.

### Step 6: DAX Calculations
Created measures for important KPIs such as:
- Total Sales
- Total Profit
- Sales by Region
- Monthly Sales
- Monthly Profit
- YoY Sales
- YoY Profit

### Step 7: Dashboard Creation
Created interactive Power BI visuals including:
- KPI Cards
- Donut Charts
- Bar Charts
- Line Charts
- Sales by Category
- Sales by Sub-Category
- Sales by Region
- Sales by Ship Mode
- Sales by Payment Mode

### Step 8: YoY Analysis
Created monthly Sales and Profit comparisons for different years to identify performance trends.

### Step 9: Sales Forecasting
Used Power BI forecasting functionality to analyze historical sales data and generate a **15-day sales forecast**.

### Step 10: Dashboard Formatting
Applied consistent colors, titles, filters, and layouts to make the dashboard interactive and easy to understand.

## 📊 Key Dashboard Insights

The dashboard helps users understand:

- Overall sales performance
- Profit trends over time
- Regional performance
- Best-performing categories and sub-categories
- Customer segment contribution
- Payment mode distribution
- Shipping mode performance
- Future sales trends
